# Anagram Signature

## Definition

A technique that groups or compares strings by a canonical character signature (sorted chars or count tuple). Requires: [[Hashmap]], [[Frequency Count]], [[String]].

## Description

Two strings are anagrams when they share the same signature. Used to group anagrams and validate anagram equality without nested comparisons.
