# Sliding Window

## Definition

A technique that maintains a contiguous subarray or substring and expands/shrinks its bounds while updating a running metric. Requires: [[Array]], [[Hashmap]].

## Description

Used for longest/shortest substring problems and running sums. Often paired with a hashmap of counts inside the window.
