# Graph Traversal Choice

## Definition

DFS explores depth-first (paths, cycles, components); BFS explores layer-by-layer (shortest unweighted paths). Requires: [[Depth First Search]], [[Breadth First Search]].

## Description

Pick BFS for level order / shortest path in unweighted graphs; DFS for connectivity, topological ideas, and backtracking on graphs.
