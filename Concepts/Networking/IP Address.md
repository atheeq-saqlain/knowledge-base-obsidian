## Definition

An **IP address** is a unique numeric identifier assigned to a device on a network so other devices can address and deliver data to it.

## Description

Think of an IP address like a house address on a street: it tells the network *where* a device lives so packets can be routed to the correct destination.

Every phone, laptop, server, and router on a network needs an IP address. Without one, other devices cannot reliably send traffic to that machine.

**Example (IPv4):**

```text
192.168.1.10
```

**Example (IPv6):**

```text
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

IP addresses are foundational to almost all internet communication. Higher-level systems — including DNS, Routing, and application protocols like HTTP — all assume devices can be reached at an IP address.
