# Quadratic Equation

## Definition

A quadratic equation in x is an equation that can be written as ax² + bx + c = 0 with real a, b, c and a ≠ 0. A real number α is a **root** if aα² + bα + c = 0. The roots of the equation are the same as the zeroes of the polynomial ax² + bx + c; there are at most two real roots.

## Description

Always reduce an equation to standard form (descending powers) before classifying it. If the x² terms cancel, the equation is not quadratic. Quadratic models appear in area, age, speed–distance–time, and similar word problems.
