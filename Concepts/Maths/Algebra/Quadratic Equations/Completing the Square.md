# Completing the Square

## Definition

Rewrite ax² + bx + c = 0 so that one side is a perfect square (x + d)² (or (px + q)²) equal to a constant, then take square roots to solve — provided that constant is non-negative.

## Description

Geometrically, for x² + 4x one rearranges two strips of area 2x beside an x² square and adds the missing 2² corner. Algebraically this method derives the [[Quadratic Formula]]. Prefer it when asked explicitly, or when a is awkward for mental factorisation.
