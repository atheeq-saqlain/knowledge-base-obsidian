# Solving by Factorisation

## Definition

To solve ax² + bx + c = 0 by factorisation: split the middle term so that the product of the two parts equals ac, factor into linear factors, and set each factor equal to zero.

## Description

Works when the quadratic factors over the reals (often with integer or simple radical coefficients). Equating each linear factor to zero gives the roots of the [[Quadratic Equation]].
