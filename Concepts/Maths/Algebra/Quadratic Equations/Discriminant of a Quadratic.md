# Discriminant of a Quadratic

## Definition

For ax² + bx + c = 0, the discriminant is D = b² − 4ac. If D > 0 there are two distinct real roots; if D = 0 two equal real roots x = −b/(2a); if D < 0 there are no real roots.

## Description

Check D before or after applying the [[Quadratic Formula]]. Equal-root conditions set D = 0 and solve for an unknown coefficient. Word problems that ask “is it possible?” often reduce to checking whether D ≥ 0 and discarding non-physical roots.
