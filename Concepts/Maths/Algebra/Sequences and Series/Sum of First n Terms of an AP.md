# Sum of First n Terms of an AP

## Definition

The sum of the first n terms of an [[Arithmetic Progression]] with first term a and [[Common Difference]] d is Sₙ = (n/2)[2a + (n − 1)d], or equivalently Sₙ = (n/2)(a + aₙ). If the last term is l, then Sₙ = (n/2)(a + l).

## Description

Write S = a + (a + d) + … + [a + (n − 1)d] and also S with the terms reversed. Adding term-wise gives 2S = n[2a + (n − 1)d], so Sₙ = (n/2)[2a + (n − 1)d]. When the last term l = aₙ is known, this is Sₙ = (n/2)(a + l).

Knowing any three of Sₙ, a, d, n determines the fourth. Also aₙ = Sₙ − Sₙ₋₁. If d is negative, two different n can give the same positive sum, because later negative terms can cancel.

The first n positive integers form an AP with a = 1, d = 1, so 1 + 2 + … + n = n(n + 1)/2.

Example: Sum of first 22 terms of 8, 3, −2, … (a = 8, d = −5) is (22/2)[16 + 21(−5)] = −979.
