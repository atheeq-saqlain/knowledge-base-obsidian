# nth Term of an AP

## Definition

In an [[Arithmetic Progression]] with first term a and [[Common Difference]] d, the nth term (general term) is given by aₙ = a + (n − 1)d.

## Description

The pattern is a₁ = a + (1 − 1)d, a₂ = a + (2 − 1)d, a₃ = a + (3 − 1)d, which generalises to aₙ = a + (n − 1)d.

Use this formula to find a specific term, to find n when a term is known, or to decide whether a number belongs to an AP (n must be a positive integer). If n is not a positive integer, the number is not a term of the AP.

If the AP has m terms, aₘ is the last term (sometimes written l). The kth term from the last is the (m − k + 1)th term from the start; equivalently, reverse the AP so the last term becomes the first term and the common difference changes sign.

Example: For 2, 7, 12, … (a = 2, d = 5), a₁₀ = 2 + 9×5 = 47. For 21, 18, 15, … (a = 21, d = −3), −81 is the 35th term and 0 is the 8th term.
