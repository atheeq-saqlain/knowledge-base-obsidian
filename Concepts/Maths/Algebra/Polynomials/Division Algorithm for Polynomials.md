# Division Algorithm for Polynomials

## Definition

If p(x) and g(x) are polynomials with g(x) ≠ 0, there exist unique polynomials q(x) (quotient) and r(x) (remainder) such that p(x) = g(x) · q(x) + r(x), where either r(x) = 0 or deg r(x) < deg g(x).

## Description

This is the polynomial analogue of Euclid’s division for integers. If r(x) = 0, then g(x) is a factor of p(x). Given some zeroes, form a factor, divide to get a lower-degree quotient, and find the remaining zeroes from that quotient.
