# Consistency of Linear Equations

## Definition

For a [[Pair of Linear Equations]] a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0: if a₁/a₂ ≠ b₁/b₂ the pair is consistent with a unique solution; if a₁/a₂ = b₁/b₂ ≠ c₁/c₂ it is inconsistent (no solution); if a₁/a₂ = b₁/b₂ = c₁/c₂ it is dependent and consistent (infinitely many solutions).

## Description

| Coefficient ratios | Graph | Solutions | Consistency |
| --- | --- | --- | --- |
| a₁/a₂ ≠ b₁/b₂ | Intersecting | Exactly one | Consistent |
| a₁/a₂ = b₁/b₂ = c₁/c₂ | Coincident | Infinitely many | Dependent (consistent) |
| a₁/a₂ = b₁/b₂ ≠ c₁/c₂ | Parallel | None | Inconsistent |

A dependent pair is always consistent. Use these tests before or instead of graphing when only the nature of the solution is required (for example finding k for unique, none, or infinitely many solutions).
