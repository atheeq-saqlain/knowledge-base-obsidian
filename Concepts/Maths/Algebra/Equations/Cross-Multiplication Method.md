# Cross-Multiplication Method

## Definition

For a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0 with a₁b₂ − a₂b₁ ≠ 0 (unique solution), x/(b₁c₂ − b₂c₁) = y/(c₁a₂ − c₂a₁) = 1/(a₁b₂ − a₂b₁), so x = (b₁c₂ − b₂c₁)/(a₁b₂ − a₂b₁) and y = (c₁a₂ − c₂a₁)/(a₁b₂ − a₂b₁).

## Description

Write both equations in standard form ax + by + c = 0 first. The formula applies only when the pair has a unique solution; check [[Consistency of Linear Equations]] when a₁b₂ − a₂b₁ might be zero. The cross-multiplication diagram arranges coefficients of y, then constant, then x, to build the three denominators.
