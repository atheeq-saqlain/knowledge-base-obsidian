# Cross-Multiplication Method

## Definition

For a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0 with a₁b₂ − a₂b₁ ≠ 0, the unique solution is x = (b₁c₂ − b₂c₁)/(a₁b₂ − a₂b₁) and y = (c₁a₂ − c₂a₁)/(a₁b₂ − a₂b₁).

## Description

Useful once you have standard form. Check Consistency of Linear Equations first when coefficients may give no unique solution. Often written via the cross-multiplication pattern for x : y : 1.
