# Equations Reducible to Linear Form

## Definition

Some non-linear pairs become a [[Pair of Linear Equations]] after a substitution (for example p = 1/x, q = 1/y, or u = 1/(x − y)); solve the linear pair, then recover the original variables.

## Description

Common patterns: equations in 1/x and 1/y; 1/(x − 1) and 1/(y − 2); upstream/downstream with u = 1/(x − y) and v = 1/(x + y); products such as (7x − 2y)/xy. Substitute, solve by substitution, elimination, or cross-multiplication, then invert. Check solutions in the original equations and exclude values that make a denominator zero.
