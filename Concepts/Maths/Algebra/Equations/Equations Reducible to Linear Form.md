# Equations Reducible to Linear Form

## Definition

Some non-linear pairs become a [[Pair of Linear Equations]] after a substitution (for example p = 1/x and q = 1/y); solve the linear pair, then recover the original variables.

## Description

Typical pattern: equations in 1/x and 1/y. Substitute, apply substitution/elimination/cross-multiplication, then invert. Verify in the original equations.
