# Linear Equation in Two Variables

## Definition

An equation that can be written as ax + by + c = 0, where a, b, and c are real numbers and a and b are not both zero (a² + b² ≠ 0), is a linear equation in the two variables x and y.

## Description

Geometrically, the set of solutions (x, y) is a straight line in the plane. Finding two points (for example intercepts) is enough to draw the line. Two such equations in the same variables form a pair of linear equations.
