# Substitution Method

## Definition

Solve a [[Pair of Linear Equations]] by expressing one variable from one equation in terms of the other, substituting into the second equation, then back-substituting.

## Description

Steps: (1) solve one equation for one variable; (2) substitute into the other; (3) solve the resulting one-variable equation; (4) substitute back. After substitution, an identity (true for all values) means infinitely many solutions; a contradiction (for example 0 = 9) means inconsistent. Useful for word problems once the pair is written.
