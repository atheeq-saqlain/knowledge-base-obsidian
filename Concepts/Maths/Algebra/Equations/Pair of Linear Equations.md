# Pair of Linear Equations

## Definition

Two [[Linear Equation in Two Variables]] in the same unknowns form a pair; the general form is a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0, where a₁² + b₁² ≠ 0 and a₂² + b₂² ≠ 0.

## Description

Each equation is a straight line. A common solution is a point that lies on both lines. Solving means finding all such common points — none, one, or infinitely many — using graphs or algebraic methods (substitution, elimination, cross-multiplication). Word problems are first written as such a pair, then solved.
