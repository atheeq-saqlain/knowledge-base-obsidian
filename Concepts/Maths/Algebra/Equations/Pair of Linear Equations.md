# Pair of Linear Equations

## Definition

Two linear equations in the same two variables form a pair of linear equations; the general form is a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0, where a₁² + b₁² ≠ 0 and a₂² + b₂² ≠ 0.

## Description

Each equation represents a straight line. Solving the pair means finding all (x, y) that satisfy both equations at once. Methods include graphical and algebraic (substitution, elimination, cross-multiplication).
