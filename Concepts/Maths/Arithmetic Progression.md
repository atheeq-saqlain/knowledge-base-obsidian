# Arithmetic Progression

## Definition

A list of numbers in which each term after the first is obtained by adding a fixed [[Common Difference]] to the preceding term.

## Description

The general form is a, a + d, a + 2d, a + 3d, … where a is the first term and d is the common difference (positive, negative, or zero).

A list a₁, a₂, a₃, … is an AP if aₖ₊₁ − aₖ is the same for every k. Finite APs have a last term; infinite APs do not.

Examples: 8000, 8500, 9000, … (d = 500); 100, 70, 40, 10, … (d = −30); 3, 3, 3, 3, … (d = 0).
