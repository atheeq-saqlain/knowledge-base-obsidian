# Euclid Division Lemma

## Definition

Given positive integers a and b, there exist unique integers q (quotient) and r (remainder) such that a = bq + r with 0 ≤ r < b. This is the formal statement of long division.

## Description

The possible remainders are the integers 0, 1, …, b − 1. Special cases: every integer is of the form 2q or 2q + 1; every odd integer is of the form 4q + 1 or 4q + 3; and similarly for other fixed divisors. The lemma is the basis of the [[Euclid Division Algorithm]] for computing HCF.
