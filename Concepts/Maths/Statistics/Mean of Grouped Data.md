# Mean of Grouped Data

## Definition

For grouped data, take each class mark xᵢ = (lower limit + upper limit)/2 and frequency fᵢ. The mean is x̄ = Σ(fᵢ xᵢ)/Σfᵢ (direct method). Equivalently, with assumed mean a and dᵢ = xᵢ − a: x̄ = a + Σ(fᵢ dᵢ)/Σfᵢ. With common class width h and uᵢ = (xᵢ − a)/h: x̄ = a + h · Σ(fᵢ uᵢ)/Σfᵢ (step-deviation).

## Description

Class marks stand in for all observations in a class. Prefer assumed-mean or step-deviation when the numbers are large. Inclusive classes should be made continuous before finding mid-points when needed.
