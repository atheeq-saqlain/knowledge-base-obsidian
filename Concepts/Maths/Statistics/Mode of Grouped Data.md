# Mode of Grouped Data

## Definition

The modal class is the class with the greatest frequency. Then
Mode = l + ((f₁ − f₀)/(2f₁ − f₀ − f₂)) · h,
where l is the lower limit of the modal class, h the class width, f₁ its frequency, f₀ the preceding frequency, and f₂ the succeeding frequency.

## Description

Mode is the most frequent value; for grouped data the formula interpolates within the modal class. Empirically, 3 Median ≈ Mode + 2 Mean for many distributions.
