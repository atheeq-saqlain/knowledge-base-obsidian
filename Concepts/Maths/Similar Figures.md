# Similar Figures

## Definition

Two figures are similar if they have the same shape but not necessarily the same size. All congruent figures are similar, but similar figures need not be congruent.

## Description

All circles are similar; all squares are similar; all equilateral triangles are similar. A circle and a square are not similar.

Two polygons with the same number of sides are similar if (i) corresponding angles are equal and (ii) corresponding sides are in the same ratio (proportional). Neither condition alone is enough.
