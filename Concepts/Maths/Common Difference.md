# Common Difference

## Definition

The constant difference between consecutive terms of a sequence, obtained as aₖ₊₁ − aₖ when that difference is the same for every k; it may be positive, negative, or zero.

## Description

Denoted by d. In an arithmetic progression it is the fixed number added to each term to get the next. Once you know the list has a constant step, it is enough to compute d from any one pair of consecutive terms (always subtract the earlier term from the later: aₖ₊₁ − aₖ).

Examples: for 6, 9, 12, 15, … d = 3; for 6, 3, 0, −3, … d = −3; for 2, 2, 2, 2, … d = 0.
