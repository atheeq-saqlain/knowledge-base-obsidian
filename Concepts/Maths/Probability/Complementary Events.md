# Complementary Events

## Definition

For an event E, the complementary event “not E” is denoted Ē. Then P(E) + P(Ē) = 1, so P(Ē) = 1 − P(E).

## Description

Use the complement when “not E” is easier to count than E (e.g. probability of not drawing an ace). Builds on [[Theoretical Probability]].
