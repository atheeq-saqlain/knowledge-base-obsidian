# Theoretical Probability

## Definition

When all outcomes of an experiment are equally likely, the theoretical probability of an event E is P(E) = (number of outcomes favourable to E) / (number of all possible outcomes). Always 0 ≤ P(E) ≤ 1. The sum of the probabilities of all elementary events is 1.

## Description

An elementary event is a single outcome. Outcomes are equally likely if none is preferred (e.g. a fair die or coin). Geometric probability uses area (or length) ratios when a point is equally likely to fall anywhere in a region. Related: [[Complementary Events]], [[Impossible Event]], [[Certain Event]].
