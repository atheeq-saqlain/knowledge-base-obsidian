# SSS Similarity Criterion

## Definition

If in two triangles the corresponding sides are in the same ratio (proportional), then the corresponding angles are equal and the triangles are [[Similar Triangles]].

## Description

If AB/PQ = BC/QR = CA/RP, then ΔABC ~ ΔPQR. Match sides carefully so that the order of vertices reflects correspondence. Unlike SSS congruence, only ratios of sides are required, not equal lengths.
