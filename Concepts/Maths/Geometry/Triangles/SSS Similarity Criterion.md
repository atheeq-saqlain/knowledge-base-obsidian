# SSS Similarity Criterion

## Definition

If in two triangles the corresponding sides are in the same ratio (proportional), then the corresponding angles are equal and the triangles are similar.

## Description

If AB/PQ = BC/QR = CA/RP, then ΔABC ~ ΔPQR. Match sides carefully so that the order of vertices reflects correspondence.
