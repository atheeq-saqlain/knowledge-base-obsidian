# Congruent Figures

## Definition

Two geometric figures are congruent if they have the same shape and the same size.

## Description

Congruence is similarity with scale factor 1. All congruent figures are similar, but similar figures need not be congruent. Matching corresponding parts is written with the symbol ≅.
