# Division of a Line Segment in a Given Ratio

## Definition

To divide a line segment AB in the ratio m : n using ruler and compass, draw a ray from A, mark m + n equal steps, join the last point to B, and draw through the mth point a line parallel to that join to meet AB at the dividing point.

## Description

Uses Basic Proportionality Theorem: if A₃C ∥ A₅B then AC/CB = 3/2 when dividing in 3 : 2. An alternative construction uses rays on both sides with m steps on one and n on the other.

Example: dividing a 7.6 cm segment in 5 : 8 gives parts in ratio 5 : 8.
