# Equal Tangents from External Point

## Definition

The lengths of the two tangents drawn from an external point to a [[Circle]] are equal.

## Description

If PQ and PR are tangents from external point P touching at Q and R, with centre O, then PQ = PR. Proof: radii OQ and OR are perpendicular to the tangents, so right triangles OQP and ORP are congruent by RHS (OQ = OR, OP common), hence PQ = PR by CPCT. Alternatively use Pythagoras. Deduction: OP bisects ∠QPR. Used for angle problems (for example ∠PTQ = 360° − ∠POQ − 180° when both radii are perpendicular to the tangents), circumscribed polygons (equal tangent segments from each vertex), and length calculations.
