# Equal Tangents from External Point

## Definition

The lengths of the two tangents drawn from an external point to a circle are equal.

## Description

If PQ and PR are tangents from external point P touching at Q and R, then PQ = PR. Proof uses radii ⊥ tangents and RHS congruence (or Pythagoras). Used for circumscribed polygons and length problems.
