# nth Term of an AP

## Definition

In an [[Arithmetic Progression]] with first term a and [[Common Difference]] d, the nth term (general term) is given by aₙ = a + (n − 1)d.

## Description

Use this formula to find a specific term, to find n when a term is known, or to decide whether a number belongs to an AP (n must be a positive integer).

If the AP has m terms, aₘ is the last term (sometimes written l).

Example: For 2, 7, 12, … (a = 2, d = 5), a₁₀ = 2 + 9×5 = 47.
