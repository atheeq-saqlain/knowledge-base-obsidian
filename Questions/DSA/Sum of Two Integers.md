# Sum of Two Integers

## Statement

Return the sum of two integers without using `+` or `-` operators.

## Description

Given two integers `a` and `b`, return the sum of the two integers without using the `+` and `-` operators.

**Example 1:**

```java
Input: a = 1, b = 1

Output: 2
```

**Example 2:**

```java
Input: a = 4, b = 7

Output: 11
```

**Constraints:**

- `-1000 <= a, b <= 1000`
