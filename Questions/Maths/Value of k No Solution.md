# Value of k No Solution

## Statement

For which value of k will the following pair of linear equations have no solution?

3x + y = 1  
(2k − 1)x + (k − 1)y = 2k + 1

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.5, Question 2(ii).

## Correct Answer

k = 2

Need a₁/a₂ = b₁/b₂ ≠ c₁/c₂ ⇒ 3/(2k−1) = 1/(k−1) ≠ 1/(2k+1), giving k = 2.
