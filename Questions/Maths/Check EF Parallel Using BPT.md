# Check EF Parallel Using BPT

## Statement

E and F are points on the sides PQ and PR respectively of ΔPQR. For each case, state whether EF ∥ QR:

(i) PE = 3.9 cm, EQ = 3 cm, PF = 3.6 cm, FR = 2.4 cm
(ii) PE = 4 cm, QE = 4.5 cm, PF = 8 cm, RF = 9 cm
(iii) PQ = 1.28 cm, PR = 2.56 cm, PE = 0.18 cm, PF = 0.36 cm

## Description

Source: KTBS Class 10 Maths Part I, Exercise 2.2, Question 2.

## Correct Answer

(i) No — PE/EQ = 3.9/3 = 1.3, PF/FR = 3.6/2.4 = 1.5 (unequal).
(ii) Yes — PE/EQ = 4/4.5 = 8/9, PF/RF = 8/9.
(iii) Yes — PE/EQ = 0.18/1.10 = 9/55 and PF/FR = 0.36/2.20 = 9/55.

[[Basic Proportionality Theorem]]
