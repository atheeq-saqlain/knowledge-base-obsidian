# Examples Satisfying Division Algorithm

## Statement

Give examples of polynomials p(x), g(x), q(x) and r(x), which satisfy the division algorithm and

(i) deg p(x) = deg q(x)
(ii) deg q(x) = deg r(x)
(iii) deg r(x) = 0

## Description

Source: KTBS Class 10 Maths Part II, Exercise 9.3, Question 5.

## Correct Answer

Many examples work; one set:

(i) p(x) = x² + x, g(x) = 2, q(x) = (1/2)x² + (1/2)x, r(x) = 0 (deg p = deg q = 2)
(ii) p(x) = x³ + x² + x + 1, g(x) = x², q(x) = x + 1, r(x) = x + 1 (deg q = deg r = 1)
(iii) p(x) = x² + 1, g(x) = x, q(x) = x, r(x) = 1 (deg r = 0)
