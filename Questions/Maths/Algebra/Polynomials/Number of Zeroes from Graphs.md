# Number of Zeroes from Graphs

## Statement

Find the number of zeroes of p(x) in each case from the given graphs (textbook Fig. for Exercise 9.1):

(i) A line parallel to the x-axis
(ii) A curve intersecting the x-axis at one point
(iii) A curve intersecting the x-axis at three points
(iv) A parabola intersecting the x-axis at two points
(v) A curve intersecting the x-axis at four points
(vi) A curve touching/intersecting the x-axis at three points

## Description

Source: KTBS Class 10 Maths Part II, Exercise 9.1, Question 1.

## Correct Answer

(i) 0
(ii) 1
(iii) 3
(iv) 2
(v) 4
(vi) 3
