# Other Zeroes Given 2 Plus Minus Root 3

## Statement

If two zeroes of the polynomial x⁴ − 6x³ − 26x² + 138x − 35 are 2 ± √3, find the other zeroes.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 9.4 (Optional), Question 4.

## Correct Answer

7 and −5

Quadratic factor from the given zeroes: x² − 4x + 1. Division yields x² − 2x − 35 = (x − 7)(x + 5).
