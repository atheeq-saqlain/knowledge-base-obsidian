# Roots by Factorisation

## Statement

Find the roots of the following quadratic equations by factorisation:

(i) x² − 3x − 10 = 0
(ii) 2x² + x − 6 = 0
(iii) √2 x² + 7x + 5√2 = 0
(iv) 2x² − x + 1/8 = 0
(v) 100x² − 20x + 1 = 0

## Description

Source: KTBS Class 10 Maths Part II, Exercise 10.2, Question 1.

## Correct Answer

(i) 5, −2
(ii) 3/2, −2
(iii) −5/√2, −√2 (or −(5√2)/2, −√2)
(iv) 1/4, 1/4
(v) 1/10, 1/10
