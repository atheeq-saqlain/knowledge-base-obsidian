# Check Whether Quadratic Equations

## Statement

Check whether the following are quadratic equations:

(i) (x + 1)² = 2(x − 3)
(ii) x² − 2x = (−2)(3 − x)
(iii) (x − 2)(x + 1) = (x − 1)(x + 3)
(iv) (x − 3)(2x + 1) = x(x + 5)
(v) (2x − 1)(x − 3) = (x + 5)(x − 1)
(vi) x² + 3x + 1 = (x − 2)²
(vii) (x + 2)³ = 2x(x² − 1)
(viii) x³ − 4x² − x + 1 = (x − 2)³

## Description

Source: KTBS Class 10 Maths Part II, Exercise 10.1, Question 1.

## Correct Answer

(i) Yes — x² + 7 = 0
(ii) Yes — x² − 4x + 6 = 0
(iii) No — reduces to a linear equation
(iv) Yes — x² − 10x − 3 = 0
(v) Yes — x² − 11x + 8 = 0
(vi) No — reduces to a linear equation
(vii) No — cubic after simplification
(viii) Yes — 2x² − 13x + 9 = 0
