# Roots by Completing the Square

## Statement

Find the roots of the following quadratic equations, if they exist, by the method of completing the square:

(i) 2x² − 7x + 3 = 0
(ii) 2x² + x − 4 = 0
(iii) 4x² + 4√3 x + 3 = 0
(iv) 2x² + x + 4 = 0

## Description

Source: KTBS Class 10 Maths Part II, Exercise 10.3, Question 1.

## Correct Answer

(i) 3, 1/2
(ii) (−1 ± √33)/4
(iii) −√3/2, −√3/2
(iv) No real roots
