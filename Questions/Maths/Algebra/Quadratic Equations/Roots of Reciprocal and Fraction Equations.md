# Roots of Reciprocal and Fraction Equations

## Statement

Find the roots of the following equations:

(i) x − 1/x = 3 (x ≠ 0)
(ii) 1/(x + 4) − 1/(x − 7) = 11/30 (x ≠ −4, 7)

## Description

Source: KTBS Class 10 Maths Part II, Exercise 10.3, Question 3.

## Correct Answer

(i) (3 ± √13)/2
(ii) 1, 2
