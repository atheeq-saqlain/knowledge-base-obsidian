# Represent Situations as Quadratic Equations

## Statement

Represent the following situations in the form of quadratic equations:

(i) The area of a rectangular plot is 528 m². The length of the plot is one more than twice its breadth. Find the length and breadth of the plot.
(ii) The product of two consecutive positive integers is 306. Find the integers.
(iii) Rohan’s mother is 26 years older than him. The product of their ages 3 years from now will be 360. Find Rohan’s present age.
(iv) A train travels 480 km at a uniform speed. If the speed had been 8 km/h less, it would have taken 3 hours more for the same distance. Find the speed of the train.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 10.1, Question 2.

## Correct Answer

(Forming the equations only, as asked.)

(i) If breadth = x, then 2x² + x − 528 = 0
(ii) If the integers are n and n + 1, then n² + n − 306 = 0
(iii) If Rohan’s age = x, then x² + 32x − 273 = 0
(iv) If speed = x, then x² − 8x − 1280 = 0
