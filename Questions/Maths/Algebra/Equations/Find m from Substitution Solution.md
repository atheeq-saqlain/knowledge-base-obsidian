# Find m from Substitution Solution

## Statement

Solve 2x + 3y = 11 and 2x − 4y = −24, and hence find the value of m for which y = mx + 3.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.3, Question 2.

## Correct Answer

x = −1, y = 13/3; then 13/3 = −m + 3 ⇒ m = −4/3.
