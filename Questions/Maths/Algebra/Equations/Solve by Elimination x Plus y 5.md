# Solve by Elimination x Plus y 5

## Statement

Solve the following pair of linear equations by the elimination method (and check by substitution):

x + y = 5  
2x − 3y = 4

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.4, Question 1(i).

## Correct Answer

x = 19/5, y = 6/5

Multiply first by 3: 3x + 3y = 15. Add to second: 5x = 19 ⇒ x = 19/5, y = 6/5.
