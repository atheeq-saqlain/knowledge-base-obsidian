# Solve by Elimination x Plus y 5

## Statement

Solve the following pairs of linear equations by the elimination method and the substitution method:

(i) x + y = 5 ; 2x − 3y = 4
(ii) 3x + 4y = 10 ; 2x − 2y = 2
(iii) 3x − 5y − 4 = 0 ; 9x = 2y + 7
(iv) x/2 + 2y/3 = −1 ; x − y/3 = 3

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.4, Question 1.

## Correct Answer

(i) x = 19/5, y = 6/5
(ii) x = 3, y = 1/4
(iii) x = 1, y = −1/5
(iv) x = 2, y = −3
