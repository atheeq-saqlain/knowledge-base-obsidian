# Solve by Substitution x Plus y 14

## Statement

Solve the following pairs of linear equations by the substitution method:

(i) x + y = 14 ; x − y = 4
(ii) s − t = 3 ; s/3 + t/2 = 6
(iii) 3x − y = 3 ; 9x − 3y = 9
(iv) 0.2x + 0.3y = 1.3 ; 0.4x + 0.5y = 2.3
(v) √2 x + √3 y = 0 ; √3 x − √8 y = 0
(vi) (3x)/2 − (5y)/3 = −2 ; x/3 + y/2 = 13/6

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.3, Question 1.

## Correct Answer

(i) x = 9, y = 5
(ii) s = 9, t = 6
(iii) Infinitely many solutions (dependent equations)
(iv) x = 2, y = 3
(v) x = 0, y = 0
(vi) x = 2, y = 3
