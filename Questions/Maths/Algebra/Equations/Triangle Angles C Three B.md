# Triangle Angles C Three B

## Statement

In a ΔABC, ∠C = 3∠B = 2(∠A + ∠B). Find the three angles.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.7, Question 5.

## Correct Answer

∠A = 20°, ∠B = 40°, ∠C = 120°.
