# Reciprocal Linear Equations

## Statement

Solve the following pairs of equations by reducing them to a pair of linear equations:

(i) 1/(2x) + 1/(3y) = 2 ; 1/(3x) + 1/(2y) = 13/6
(ii) 2/√x + 3/√y = 2 ; 4/√x − 9/√y = −1
(iii) 4/x + 3y = 14 ; 3/x − 4y = 23
(iv) 5/(x − 1) + 1/(y − 2) = 2 ; 6/(x − 1) − 3/(y − 2) = 1
(v) (7x − 2y)/xy = 5 ; (8x + 7y)/xy = 15
(vi) 6x + 3y = 6xy ; 2x + 4y = 5xy
(vii) 10/(x + y) + 2/(x − y) = 4 ; 15/(x + y) − 5/(x − y) = −2
(viii) 1/(3x + y) + 1/(3x − y) = 3/4 ; 1/(2(3x + y)) − 1/(2(3x − y)) = −1/8

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.6, Question 1.

## Correct Answer

(i) x = 1/2, y = 1/3. Let u = 1/x, v = 1/y ⇒ u/2 + v/3 = 2, u/3 + v/2 = 13/6 ⇒ u = 2, v = 3.
(ii) x = 4, y = 9
(iii) x = 1/5, y = −2
(iv) x = 4, y = 5
(v) x = 1, y = 1
(vi) x = 1, y = 2
(vii) x = 3, y = 2
(viii) x = 1, y = 1
