# Reciprocal Linear Equations

## Statement

Solve: 2/x + 3/y = 13 and 5/x − 4/y = −2.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.6, Question 1(i).

## Correct Answer

x = 1/2, y = 1/3

Substitute p = 1/x, q = 1/y → 2p + 3q = 13, 5p − 4q = −2 → p = 2, q = 3.
