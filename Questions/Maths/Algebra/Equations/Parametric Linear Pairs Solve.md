# Parametric Linear Pairs Solve

## Statement

Solve the following pairs of linear equations:

(i) px + qy = p − q ; qx − py = p + q
(ii) ax + by = c ; bx + ay = 1 + c
(iii) x/a − y/b = 0 ; ax + by = a² + b²
(iv) (a − b)x + (a + b)y = a² − 2ab − b² ; (a + b)(x + y) = a² + b²
(v) 152x − 378y = −74 ; −378x + 152y = −604

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.7, Question 7.

## Correct Answer

(i)–(iv) Solve symbolically for x, y in terms of the parameters (standard textbook solutions).
(v) x = 2, y = 1 (after simplifying / cross-multiplication).
