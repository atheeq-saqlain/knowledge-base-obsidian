# Which Lists Form an AP

## Statement

Which of the following are APs? If they form an AP, find the common difference d and write three more terms.

(i) 2, 4, 8, 16, …

(ii) 5/2, 3, 7/2, 4, …

(iii) −1.2, −3.2, −5.2, −7.2, …

(iv) −10, −6, −2, 2, …

(v) 3, 3 + √2, 3 + 2√2, 3 + 3√2, …

(vi) 0.2, 0.22, 0.222, 0.2222, …

(vii) 0, −4, −8, −12, …

(viii) −1/2, −1/2, −1/2, −1/2, …

(ix) 1, 3, 9, 27, …

(x) a, 2a, 3a, 4a, …

(xi) a, a², a³, a⁴, …

(xii) √2, √8, √18, √32, …

(xiii) √3, √6, √9, √12, …

(xiv) 1², 3², 5², 7², …

(xv) 1², 5², 7², 73, …

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.1, Question 4.

## Correct Answer

(i) Not an AP (differences 2, 4, 8, …).

(ii) AP, d = 1/2. Next three terms: 9/2, 5, 11/2.

(iii) AP, d = −2. Next three terms: −9.2, −11.2, −13.2.

(iv) AP, d = 4. Next three terms: 6, 10, 14.

(v) AP, d = √2. Next three terms: 3 + 4√2, 3 + 5√2, 3 + 6√2.

(vi) Not an AP.

(vii) AP, d = −4. Next three terms: −16, −20, −24.

(viii) AP, d = 0. Next three terms: −1/2, −1/2, −1/2.

(ix) Not an AP (geometric).

(x) AP, d = a. Next three terms: 5a, 6a, 7a.

(xi) Not an AP in general.

(xii) AP (√2, 2√2, 3√2, 4√2), d = √2. Next three terms: 5√2, 6√2, 7√2.

(xiii) Not an AP.

(xiv) Not an AP (differences 8, 16, 24, …).

(xv) AP (1, 25, 49, 73), d = 24. Next three terms: 97, 121, 145.
