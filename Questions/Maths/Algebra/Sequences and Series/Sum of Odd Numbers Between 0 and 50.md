# Sum of Odd Numbers Between 0 and 50

## Statement

Find the sum of the odd numbers between 0 and 50.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.3, Question 14.

## Correct Answer

625

The AP is 1, 3, …, 49. n = 25. S = (25/2)(1 + 49) = 625.
