# Sum of APs to Given Number of Terms

## Statement

Find the sum of the following APs:

(i) −37, −33, −29, … to 12 terms

(ii) 0.6, 1.7, 2.8, … to 100 terms

(iii) 1/15, 1/12, 1/10, … to 11 terms

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.3, Question 1(ii)–(iv). Companion to [[Sum of AP 2 7 12 to 10 Terms]] (Question 1(i)).

## Correct Answer

(i) −180. a = −37, d = 4, n = 12. S₁₂ = 6[−74 + 44] = −180.

(ii) 5505. a = 0.6, d = 1.1, n = 100. S₁₀₀ = 50[1.2 + 99×1.1] = 50×110.1 = 5505.

(iii) 33/20. a = 1/15, d = 1/12 − 1/15 = 1/60, n = 11.
S₁₁ = (11/2)[2/15 + 10×(1/60)] = (11/2)(3/10) = 33/20.
