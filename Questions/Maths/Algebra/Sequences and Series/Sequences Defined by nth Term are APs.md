# Sequences Defined by nth Term are APs

## Statement

Show that a₁, a₂, …, aₙ, … form an AP where aₙ is defined as below. Also find the sum of the first 15 terms in each case.

(i) aₙ = 3 + 4n

(ii) aₙ = 9 − 5n

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.3, Question 10.

## Correct Answer

(i) a₁ = 7, a₂ = 11, a₃ = 15, so d = 4 is constant — an AP. S₁₅ = (15/2)[14 + 14×4] = 525.

(ii) a₁ = 4, a₂ = −1, a₃ = −6, so d = −5 is constant — an AP. S₁₅ = (15/2)[8 + 14×(−5)] = −465.

In general aₙ₊₁ − aₙ is independent of n, so the sequence is an AP.
