# Find Missing AP Quantities

## Statement

In an AP:

(i) given a = 5, d = 3, aₙ = 50, find n and Sₙ.

(ii) given a = 7, a₁₃ = 35, find d and S₁₃.

(iii) given a₁₂ = 37, d = 3, find a and S₁₂. (Some editions print a₁₂ = 31.)

(iv) given a₃ = 15, S₁₀ = 125, find d and a₁₀.

(v) given d = 5, S₉ = 75, find a and a₉.

(vi) given a = 2, d = 8, Sₙ = 90, find n and aₙ.

(vii) given a = 8, aₙ = 62, Sₙ = 210, find n and d.

(viii) given aₙ = 4, d = 2, Sₙ = −14, find n and a.

(ix) given a = 3, n = 8, S = 192, find d.

(x) given l = 28, S = 144 and there are 9 terms, find a.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.3, Question 3.

## Correct Answer

(i) n = 16, Sₙ = 440

(ii) d = 7/3, S₁₃ = 273

(iii) a = 4, S₁₂ = 246 (if a₁₂ = 31: a = −2, S₁₂ = 174)

(iv) d = −1, a₁₀ = 8

(v) a = −35/3, a₉ = 85/3

(vi) n = 5, aₙ = 34

(vii) n = 6, d = 54/5

(viii) n = 7, a = −8

(ix) d = 6

(x) a = 4
