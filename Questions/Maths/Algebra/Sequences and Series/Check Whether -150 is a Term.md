# Check Whether -150 is a Term

## Statement

Check whether −150 is a term of the AP: 11, 8, 5, 2, …

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.2, Question 6.

## Correct Answer

No. a = 11, d = −3. If −150 = 11 + (n − 1)(−3), then n − 1 = 161/3, which is not an integer. So −150 is not a term of the AP.
