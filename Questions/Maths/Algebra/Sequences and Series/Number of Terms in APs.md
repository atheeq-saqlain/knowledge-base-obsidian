# Number of Terms in APs

## Statement

Find the number of terms in each of the following APs:

(i) 7, 13, 19, …, 205

(ii) 18, 15½, 13, …, −47

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.2, Question 5.

## Correct Answer

(i) 34 terms. a = 7, d = 6, aₙ = 205 ⇒ 205 = 7 + (n − 1)×6 ⇒ n = 34.

(ii) 27 terms. a = 18, d = −5/2, aₙ = −47 ⇒ −47 = 18 + (n − 1)(−5/2) ⇒ n − 1 = 26 ⇒ n = 27.
