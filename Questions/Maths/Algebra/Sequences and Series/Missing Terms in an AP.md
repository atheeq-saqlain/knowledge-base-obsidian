# Missing Terms in an AP

## Statement

Find the missing terms in the boxes:

(i) 2, □, 26

(ii) □, 13, □, 3

(iii) 5, □, □, 9½

(iv) −4, □, □, □, □, 6

(v) □, 38, □, □, □, −22

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.2, Question 3.

## Correct Answer

(i) 14. Three terms, d = (26 − 2)/2 = 12, so 2, 14, 26.

(ii) 18, 8. Here a₂ = 13, a₄ = 3 ⇒ d = −5, a = 18. Sequence: 18, 13, 8, 3.

(iii) 13/2, 8. a = 5, a₄ = 19/2 ⇒ d = 3/2. Sequence: 5, 13/2, 8, 19/2.

(iv) −2, 0, 2, 4. a = −4, a₆ = 6 ⇒ d = 2. Sequence: −4, −2, 0, 2, 4, 6.

(v) 53, 23, 8, −7. a₂ = 38, a₆ = −22 ⇒ d = −15, a = 53. Sequence: 53, 38, 23, 8, −7, −22.
