# First Term and Common Difference of APs

## Statement

For the following APs, write the first term and the common difference:

(i) 3, 1, −1, −3, …

(ii) −5, −1, 3, 7, …

(iii) 1/3, 5/3, 9/3, 13/3, …

(iv) 0.6, 1.7, 2.8, 3.9, …

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.1, Question 3.

## Correct Answer

(i) a = 3, d = −2

(ii) a = −5, d = 4

(iii) a = 1/3, d = 4/3

(iv) a = 0.6, d = 1.1
