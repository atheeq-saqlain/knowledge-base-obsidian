# Fill nth Term Table

## Statement

Fill in the blanks in the following table, given that a is the first term, d the common difference and aₙ the nth term of the AP.

(i) a = 7, d = 3, n = 8, aₙ = …

(ii) a = −18, d = …, n = 10, aₙ = 0

(iii) a = …, d = −3, n = 18, aₙ = −5

(iv) a = −18.9, d = 2.5, n = …, aₙ = 3.6

(v) a = 3.5, d = 0, n = 105, aₙ = …

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.2, Question 1.

## Correct Answer

(i) aₙ = 28

(ii) d = 2

(iii) a = 46

(iv) n = 10

(v) aₙ = 3.5

Using aₙ = a + (n − 1)d in each row.
