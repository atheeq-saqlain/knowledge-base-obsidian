# Log Stack 200 Logs

## Statement

200 logs are stacked in the following manner: 20 logs in the bottom row, 19 in the next row, 18 in the row next to it and so on (Fig. 1.5). In how many rows are the 200 logs placed and how many logs are in the top row?

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.3, Question 19.

## Correct Answer

16 rows, with 5 logs in the top row.

a = 20, d = −1, Sₙ = 200.
200 = (n/2)[40 + (n − 1)(−1)] ⇒ n² − 41n + 400 = 0 ⇒ n = 16 or 25.
n = 25 would give a negative last term, so n = 16 and a₁₆ = 20 − 15 = 5.
