# Difference of 1000th Terms Same d

## Statement

Two APs have the same common difference. The difference between their 100th terms is 100. What is the difference between their 1000th terms?

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.2, Question 12.

## Correct Answer

100

If the first terms are a and b and the common difference is d, then
(a + 99d) − (b + 99d) = a − b = 100.
The 1000th-term difference is (a + 999d) − (b + 999d) = a − b = 100.
