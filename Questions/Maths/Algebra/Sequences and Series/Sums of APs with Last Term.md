# Sums of APs with Last Term

## Statement

Find the sums given below:

(i) 7 + 10½ + 14 + … + 84

(ii) 34 + 32 + 30 + … + 10

(iii) −5 + (−8) + (−11) + … + (−230)

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.3, Question 2.

## Correct Answer

(i) 1046.5. a = 7, d = 7/2, l = 84 ⇒ n = 23. S = (23/2)(7 + 84) = 2093/2.

(ii) 286. a = 34, d = −2, l = 10 ⇒ n = 13. S = (13/2)(34 + 10) = 286.

(iii) −8930. a = −5, d = −3, l = −230 ⇒ n = 76. S = (76/2)(−5 − 230) = −8930.
