# Semicircle Spiral Length

## Statement

A spiral is made up of successive semicircles, with centres alternately at A and B, starting with centre at A, of radii 0.5 cm, 1.0 cm, 1.5 cm, 2.0 cm, … (Fig. 1.4). What is the total length of such a spiral made up of thirteen consecutive semicircles? (Take π = 22/7.)

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.3, Question 18.

## Correct Answer

143 cm

Each semicircle has length πr, so the total length is π(0.5 + 1.0 + … + 6.5).
This AP has a = 1/2, d = 1/2, n = 13, last term 13/2.
Sum of radii = (13/2)(1/2 + 13/2) = 91/2.
Length = (22/7)×(91/2) = 143 cm.
