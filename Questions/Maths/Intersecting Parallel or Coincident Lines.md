# Intersecting Parallel or Coincident Lines

## Statement

On comparing the ratios a₁/a₂, b₁/b₂ and c₁/c₂, find out whether the lines representing the following pairs of linear equations intersect at a point, are parallel or coincident:

(i) 5x − 4y + 8 = 0 ; 7x + 6y − 9 = 0  
(ii) 9x + 3y + 12 = 0 ; 18x + 6y + 24 = 0  
(iii) 6x − 3y + 10 = 0 ; 2x − y + 9 = 0

## Description

Source: KTBS Class 10 Maths Part I, Exercise 3.2, Question 2.

## Correct Answer

(i) Intersect at a point (a₁/a₂ ≠ b₁/b₂)  
(ii) Coincident (a₁/a₂ = b₁/b₂ = c₁/c₂)  
(iii) Parallel (a₁/a₂ = b₁/b₂ ≠ c₁/c₂)
