# Point on x-axis Equidistant

## Statement

Find the point on the x-axis which is equidistant from (2, −5) and (−2, 9).

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.1, Question 7.

## Correct Answer

(−7, 0)

Let P(x, 0). Then (x−2)² + 25 = (x+2)² + 81 ⇒ −8x = 56 ⇒ x = −7.
