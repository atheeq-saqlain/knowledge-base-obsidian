# Sin Half B Plus C Equals Cos Half A

## Statement

If A, B and C are interior angles of a triangle ABC, show that
sin((B + C)/2) = cos(A/2).

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.3, Question 6.

## Correct Answer

A + B + C = 180° ⇒ (B + C)/2 = 90° − A/2 ⇒ sin((B + C)/2) = cos(A/2).
