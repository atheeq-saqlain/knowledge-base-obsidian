# Evaluate Expressions Given Cot 7 over 8

## Statement

If cot θ = 7/8, evaluate:
(i) [(1 + sin θ)(1 − sin θ)] / [(1 + cos θ)(1 − cos θ)]
(ii) cot² θ

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.1, Question 7.

## Correct Answer

(i) 49/64
(ii) 49/64

[[Trigonometric Identities]]
