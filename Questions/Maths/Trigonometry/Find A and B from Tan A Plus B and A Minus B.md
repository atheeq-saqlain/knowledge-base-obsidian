# Find A and B from Tan A Plus B and A Minus B

## Statement

If tan(A + B) = √3 and tan(A − B) = 1/√3, where 0° < A + B ≤ 90° and A > B, find A and B.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.2, Question 3.

## Correct Answer

A = 45°, B = 15°
