# Evaluate Using Complementary Angles

## Statement

Evaluate:
(i) sin 18° / cos 72°
(ii) tan 26° / cot 64°
(iii) cos 48° − sin 42°
(iv) csc 31° − sec 59°

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.3, Question 1.

## Correct Answer

(i) 1
(ii) 1
(iii) 0
(iv) 0
