# Prove Tan A Equals Cot B Implies A Plus B 90

## Statement

If tan A = cot B, prove that A + B = 90°.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.3, Question 4.

## Correct Answer

tan A = cot B = tan(90° − B) ⇒ A = 90° − B (acute angles) ⇒ A + B = 90°.
