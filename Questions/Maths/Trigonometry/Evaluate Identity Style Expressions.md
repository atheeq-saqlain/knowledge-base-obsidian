# Evaluate Identity Style Expressions

## Statement

Evaluate:
(i) (sin² 63° + sin² 27°) / (cos² 17° + cos² 73°)
(ii) sin 25° cos 65° + cos 25° sin 65°

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.4, Question 3.

## Correct Answer

(i) 1
(ii) 1
