# Evaluate Standard Angle Expressions

## Statement

Evaluate the following:

(i) sin 60° cos 30° + sin 30° cos 60°
(ii) 2 tan² 45° + cos² 30° − sin² 60°
(iii) cos 45° / (sec 30° + csc 30°)
(iv) (sin 30° + tan 45° − csc 60°) / (sec 30° + cos 60° + cot 45°)
(v) (5 cos² 60° + 4 sec² 30° − tan² 45°) / (sin² 30° + cos² 30°)

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.2, Question 1.

## Correct Answer

(i) 1
(ii) 2
(iii) (3√2 − √6)/8
(iv) (3√3 − 4)/(3√3 + 4)
(v) 67/12
