# Find A from Tan 2A Equals Cot A Minus 18

## Statement

If tan 2A = cot(A − 18°), where 2A is an acute angle, find the value of A.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.3, Question 3.

## Correct Answer

A = 36°
