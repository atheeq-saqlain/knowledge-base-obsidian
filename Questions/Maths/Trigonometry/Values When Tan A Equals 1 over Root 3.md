# Values When Tan A Equals 1 over Root 3

## Statement

In triangle ABC, right-angled at B, if tan A = 1/√3, find the value of:
(i) sin A cos C + cos A sin C
(ii) cos A cos C − sin A sin C

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.1, Question 9.

## Correct Answer

(i) 1
(ii) 0

(A = 30°, C = 60°; the expressions are sin(A+C) and cos(A+C).)
