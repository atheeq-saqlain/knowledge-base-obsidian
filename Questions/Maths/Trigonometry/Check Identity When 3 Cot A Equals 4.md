# Check Identity When 3 Cot A Equals 4

## Statement

If 3 cot A = 4, check whether (1 − tan² A)/(1 + tan² A) = cos² A − sin² A or not.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.1, Question 8.

## Correct Answer

Yes — both sides equal 7/25.
