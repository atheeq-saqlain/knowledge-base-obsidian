# Tan P Minus Cot R

## Statement

In right-angled triangle PQR (right-angled at Q), if PQ = 12 cm and PR = 13 cm, find the value of tan P − cot R.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.1, Question 2.

## Correct Answer

0

QR = 5 cm; tan P = cot R = 5/12.
