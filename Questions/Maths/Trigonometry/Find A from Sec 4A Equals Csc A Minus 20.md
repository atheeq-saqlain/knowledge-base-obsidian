# Find A from Sec 4A Equals Csc A Minus 20

## Statement

If sec 4A = csc(A − 20°), where 4A is an acute angle, find the value of A.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 11.3, Question 5.

## Correct Answer

A = 22°
