# X-axis Divides Segment Ratio

## Statement

Find the ratio in which the x-axis divides the segment joining A(1, −5) and B(−4, 5). Also find the point of division.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.2, Question 5.

## Correct Answer

Ratio 1 : 1; point (−3/2, 0).
