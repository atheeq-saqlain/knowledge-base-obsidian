# Value of k Collinear Points

## Statement

In each of the following find the value of k for which the points are collinear:
(i) (7, −2), (5, 1) and (3, k);
(ii) (8, 1), (k, −4) and (2, −5).

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.3, Question 2.

## Correct Answer

(i) k = 4.
(ii) k = 3.
