# Distance Between Origin and Point

## Statement

Find the distance between the points (0, 0) and (36, 15).

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.1, Question 2.

## Correct Answer

39.

√(36² + 15²) = √(1296 + 225) = √1521 = 39.
