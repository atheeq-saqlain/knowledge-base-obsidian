# Divide Segment into Four Equal Parts

## Statement

Find the coordinates of the points which divide the segment joining A(−2, 2) and B(2, 8) into four equal parts.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.2, Question 9.

## Correct Answer

(−1, 7/2), (0, 5), (1, 13/2).
