# Distance Between Two Points

## Statement

Find the distance between the points (2, 3) and (4, 1).

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.1, Question 1(i).

## Correct Answer

2√2 units

√[(4−2)² + (1−3)²] = √[4 + 4] = √8 = 2√2.
