# Collinear Relation x and y

## Statement

Find a relation between x and y if (x, y), (1, 2) and (7, 0) are collinear.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.4, Question 2 (Optional).

## Correct Answer

x + 3y = 7.
