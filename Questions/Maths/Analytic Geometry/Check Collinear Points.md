# Check Collinear Points

## Statement

Determine if the points (1, 5), (2, 3) and (−2, −11) are collinear.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.1, Question 3.

## Correct Answer

Yes, they are collinear.

Slopes: (3−5)/(2−1) = −2 and (−11−3)/(−2−2) = 7/2 — alternatively use area = 0 or equal distance ratios. Distances: AB = √5, BC = 5√5, AC = 6√5; AB + BC = AC, so collinear.
