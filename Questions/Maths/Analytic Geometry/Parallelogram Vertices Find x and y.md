# Parallelogram Vertices Find x and y

## Statement

If (1, 2), (4, y), (x, 6) and (3, 5) are vertices of a parallelogram taken in order, find x and y.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.2, Question 6.

## Correct Answer

x = 6, y = 3 (diagonals bisect).
