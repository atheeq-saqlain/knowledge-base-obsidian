# Values of y for Distance Ten

## Statement

Find the values of y for which the distance between P(2, −3) and Q(10, y) is 10 units.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.1, Question 8.

## Correct Answer

y = 3 or y = −9.

√[(10−2)² + (y+3)²] = 10 ⇒ 64 + (y+3)² = 100 ⇒ (y+3)² = 36 ⇒ y+3 = ±6.
