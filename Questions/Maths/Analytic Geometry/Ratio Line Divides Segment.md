# Ratio Line Divides Segment

## Statement

Determine the ratio in which the line 2x + y − 4 = 0 divides the segment joining A(2, −2) and B(3, 7).

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.4, Question 1 (Optional).

## Correct Answer

Ratio 2 : 9.
