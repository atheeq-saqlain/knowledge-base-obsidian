# Four Friends Square ABCD

## Statement

In the textbook figure of four friends seated at A(1, 1), B(4, 2), C(6, 5) and D(3, 4), Champa asks Chameli whether ABCD is a square. Chameli disagrees. Using the distance formula, find who is correct.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.1, Question 5.

## Correct Answer

AB = CD = √10, AD = BC = √13; diagonals unequal. Parallelogram but not a square — Chameli is correct.
