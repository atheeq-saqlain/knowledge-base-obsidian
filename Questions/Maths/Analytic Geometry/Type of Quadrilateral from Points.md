# Type of Quadrilateral from Points

## Statement

Name the type of quadrilateral formed, if any, by:
(i) (−1, −2), (1, 0), (−1, 2), (−3, 0);
(ii) (−3, 5), (3, 1), (0, 3), (−1, −4);
(iii) (4, 5), (7, 6), (4, 3), (1, 2).

## Description

Source: KTBS Class 10 Maths Part I, Exercise 7.1, Question 6.

## Correct Answer

(i) Square (all sides 2√2, equal diagonals).
(ii) No special type (unequal sides).
(iii) Parallelogram (opposite sides √10 and 3√2).
