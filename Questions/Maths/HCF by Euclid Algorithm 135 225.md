# HCF by Euclid Algorithm 135 225

## Statement

Use Euclid's division algorithm to find the HCF of 135 and 225.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 8.1, Question 1(i).

## Correct Answer

45

225 = 135×1 + 90; 135 = 90×1 + 45; 90 = 45×2 + 0. HCF = 45.
