# Which Term of AP is 78

## Statement

Which term of the AP: 3, 8, 13, 18, … is 78?

## Description

Source: KTBS Class 10 Maths Part I, Exercise 1.2, Question 4.

## Correct Answer

16th term.

a = 3, d = 5, aₙ = 78.
78 = 3 + (n − 1)×5 ⇒ 75 = 5(n − 1) ⇒ n − 1 = 15 ⇒ n = 16.
