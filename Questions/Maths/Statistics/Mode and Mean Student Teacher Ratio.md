# Mode and Mean Student Teacher Ratio

## Statement

Find the mode and mean of the number of students per teacher across states: 15–20, 20–25, 25–30, 30–35, 35–40, 40–45, 45–50, 50–55 with frequencies 3, 8, 9, 10, 3, 0, 0, 2.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 13.2, Question 4.

## Correct Answer

Mode = 30.625; mean ≈ 29.21
