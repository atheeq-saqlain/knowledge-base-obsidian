# More Than Ogive Wheat Production

## Statement

Change the wheat production yield distribution into a more-than type cumulative frequency distribution and draw its ogive: yield (kg/ha) 50–55, 55–60, 60–65, 65–70, 70–75, 75–80 with frequencies 2, 8, 12, 24, 38, 16.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 13.4, Question 3.

## Correct Answer

More-than cf: ≥50: 100; ≥55: 98; ≥60: 90; ≥65: 78; ≥70: 54; ≥75: 16; (≥80: 0). Plot lower limits against these cf values.
