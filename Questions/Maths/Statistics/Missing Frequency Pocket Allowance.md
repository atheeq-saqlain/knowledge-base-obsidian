# Missing Frequency Pocket Allowance

## Statement

The mean daily pocket allowance of children in a locality is ₹18. The distribution has classes 11–13, 13–15, 15–17, 17–19, 19–21, 21–23, 23–25 with frequencies 7, 6, 9, 13, f, 5, 4. Find the missing frequency f.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 13.1, Question 3.

## Correct Answer

f = 20
