# Median Length of Leaves

## Statement

Find the median length of 40 leaves measured to the nearest millimetre: lengths 118–126, 127–135, 136–144, 145–153, 154–162, 163–171, 172–180 with frequencies 3, 5, 9, 12, 5, 4, 2. (Convert to continuous classes first.)

## Description

Source: KTBS Class 10 Maths Part II, Exercise 13.3, Question 4.

## Correct Answer

146.75 mm
