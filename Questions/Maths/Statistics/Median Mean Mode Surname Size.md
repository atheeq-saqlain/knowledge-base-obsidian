# Median Mean Mode Surname Size

## Statement

In a survey of 100 surnames, the number of letters are in classes 1–4, 4–7, 7–10, 10–13, 13–16, 16–19 with frequencies 6, 30, 40, 16, 4, 4. Find the median, mean and modal size of the surnames.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 13.3, Question 6.

## Correct Answer

Median = 8.05; mean = 8.32; mode ≈ 7.88
