# Mode Cars Passing a Spot

## Statement

Find the mode of the number of cars passing a spot: classes 0–10, 10–20, …, 70–80 with frequencies 7, 14, 13, 12, 20, 11, 15, 8.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 13.2, Question 6.

## Correct Answer

≈ 44.7 cars
