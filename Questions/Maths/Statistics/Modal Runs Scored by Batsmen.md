# Modal Runs Scored by Batsmen

## Statement

Find the modal runs scored by batsmen: runs 3000–4000, …, 10000–11000 with frequencies 4, 18, 9, 7, 6, 3, 1, 1.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 13.2, Question 5.

## Correct Answer

≈ 4608.7 runs
