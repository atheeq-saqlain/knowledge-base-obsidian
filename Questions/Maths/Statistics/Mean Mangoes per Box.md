# Mean Mangoes per Box

## Statement

Calculate the mean number of mangoes kept in a packing box from the distribution: number of mangoes 50–52, 53–55, 56–58, 59–61, 62–64 with frequencies 15, 110, 135, 115, 25.

## Description

Source: KTBS Class 10 Maths Part II, Exercise 13.1, Question 5.

## Correct Answer

57.19 (approx.)

(Use continuous class marks 51, 54, 57, 60, 63.)
