# Same Base Area Ratio AO DO

## Description

Source: KTBS Class 10 Maths Part I, Exercise 2.4, Question 3.

## Correct Answer

Triangles with the same base BC have heights from A and D to line BC proportional to AO and DO along the line through A, O, D; alternatively use common apex argument. Thus ar(ABC)/ar(DBC) = AO/DO.
