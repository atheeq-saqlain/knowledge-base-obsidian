# Angles in Similar Triangles ODC OBA

## Statement

In Fig. 2.35, ΔODC ~ ΔOBA, ∠BOC = 125° and ∠CDO = 70°. Find ∠DOC, ∠DCO and ∠OAB.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 2.3, Question 2.

## Correct Answer

∠DOC = 55° (adjacent on a straight line / vertical angles as in the figure). In ΔODC: ∠DCO = 180° − 70° − 55° = 55°. By similarity, ∠OAB = ∠OCD = 55°.
