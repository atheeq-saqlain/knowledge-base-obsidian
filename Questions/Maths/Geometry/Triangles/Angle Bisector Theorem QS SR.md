# Angle Bisector Theorem QS SR

## Statement

## Description

Source: KTBS Class 10 Maths Part I, Exercise 2.6, Question 1.

## Correct Answer

Angle-bisector theorem: prove via similar triangles or equal-area / law-of-sines method that QS/SR = PQ/PR.
