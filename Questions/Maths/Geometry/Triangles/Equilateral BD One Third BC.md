# Equilateral BD One Third BC

## Statement

In an equilateral triangle ABC, D is a point on side BC such that BD = (1/3) BC. Prove that 9 AD² = 7 AB².

## Description

Source: KTBS Class 10 Maths Part I, Exercise 2.5, Question 15.

## Correct Answer

Let AB = BC = CA = 3x so BD = x, DC = 2x. Drop altitude or use Pythagoras / Apollonius; obtain 9 AD² = 7 AB².
