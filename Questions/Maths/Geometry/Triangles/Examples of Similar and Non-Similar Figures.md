# Examples of Similar and Non-Similar Figures

## Statement

Give two different examples of a pair of:

(i) similar figures

(ii) non-similar figures

## Description

Source: KTBS Class 10 Maths Part I, Exercise 2.1, Question 2.

## Correct Answer

(i) Any two circles; any two squares (or any two equilateral triangles).

(ii) A circle and a triangle; a square and a rectangle that is not a square (angles match for the rectangle/square case only if it is a square — a typical accepted pair is a triangle and a pentagon, or a circle and a square).
