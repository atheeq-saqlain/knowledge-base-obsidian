# Prove BF FE Equals BE EC

## Statement

In Fig. 2.19, DE ∥ AC and DF ∥ AE. Prove that BF/FE = BE/EC.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 2.2, Question 4.

## Correct Answer

Apply BPT in ΔABC (or the relevant triangle) with the given parallels to obtain BF/FE = BD/DA and BE/EC = BD/DA; hence BF/FE = BE/EC.
