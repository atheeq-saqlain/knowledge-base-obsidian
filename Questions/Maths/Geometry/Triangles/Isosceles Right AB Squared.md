# Isosceles Right AB Squared

## Statement

ABC is an isosceles triangle right-angled at C. Prove that AB² = 2 AC².

## Description

Source: KTBS Class 10 Maths Part I, Exercise 2.5, Question 4.

## Correct Answer

AC = BC. By Pythagoras: AB² = AC² + BC² = 2 AC².
