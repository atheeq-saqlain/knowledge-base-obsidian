# Equilateral Altitude Side 2a

## Statement

ABC is an equilateral triangle of side 2a. Find each of its altitudes.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 2.5, Question 6.

## Correct Answer

Altitude = √((2a)² − a²) = √(4a² − a²) = a√3.

## Core Concept

[[Pythagoras Theorem]]
