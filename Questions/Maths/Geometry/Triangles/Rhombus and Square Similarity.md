# Rhombus and Square Similarity

## Statement

State whether the following quadrilaterals are similar or not: a rhombus of side 1.5 cm and a square of side 3 cm.

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="420" height="200" viewBox="0 0 420 200">
  <rect width="420" height="200" fill="#f8fafc" stroke="#e2e8f0"/>
  <polygon points="90,40 150,70 90,160 30,130" fill="#fff" stroke="#0f172a" stroke-width="2.5"/>
  <rect x="250" y="45" width="110" height="110" fill="#fff" stroke="#0f172a" stroke-width="2.5"/>
  <text x="62" y="188" font-family="Segoe UI, Arial, sans-serif" font-size="13" fill="#334155">side 1.5 cm</text>
  <text x="262" y="188" font-family="Segoe UI, Arial, sans-serif" font-size="13" fill="#334155">side 3 cm</text>
</svg>
```

## Description

## Correct Answer

Not similar. Corresponding sides can be proportional (scale 1 : 2), but a general rhombus need not have all angles 90°, so corresponding angles are not all equal.
