# Angle POA When Tangents Inclined 80

## Statement

If tangents PA and PB from a point P to a circle with centre O are inclined to each other at an angle of 80°, then ∠POA is equal to

(A) 50° (B) 60° (C) 70° (D) 80°

## Description

Source: KTBS Class 10 Maths Part I, Exercise 4.2, Question 3.

## Correct Answer

(A) 50°

∠OAP = ∠OBP = 90°. OP bisects ∠APB, so ∠APO = 40°. In right ΔOAP: ∠POA = 90° − 40° = 50°.
