# Angle Between Tangents PTQ

## Statement

If TP and TQ are the two tangents to a circle with centre O so that ∠POQ = 110°, then ∠PTQ is equal to

(A) 60° (B) 70° (C) 80° (D) 90°

## Description

Source: KTBS Class 10 Maths Part I, Exercise 4.2, Question 2.

## Correct Answer

(B) 70°

∠OPT = ∠OQT = 90°. Quadrilateral OPTQ: ∠PTQ = 360° − 90° − 90° − 110° = 70°.
