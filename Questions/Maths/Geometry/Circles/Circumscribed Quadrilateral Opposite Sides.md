# Circumscribed Quadrilateral Opposite Sides

## Statement

A quadrilateral ABCD is drawn to circumscribe a circle. Prove that AB + CD = AD + BC.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 4.2, Question 8.

## Correct Answer

Equal tangent segments from each vertex: let the lengths from A, B, C, D be as usual. Then AB + CD = (sums of tangent lengths) = AD + BC.
