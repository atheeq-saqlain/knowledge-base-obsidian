# Parallelogram Circumscribing Is Rhombus

## Statement

Prove that the parallelogram circumscribing a circle is a rhombus.

## Description


## Correct Answer

Adjacent sides are equal by equal tangent lengths from each vertex ⇒ all sides equal ⇒ rhombus.

[[Equal Tangents from External Point]]
