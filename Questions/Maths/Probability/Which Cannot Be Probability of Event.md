# Which Cannot Be Probability of Event

## Statement

Which of the following cannot be the probability of an event?

(A) 2/3  (B) −1.5  (C) 15%  (D) 0.7

## Description

Source: KTBS Class 10 Maths Part II, Exercise 14.1, Question 4.

## Correct Answer

(B) −1.5
