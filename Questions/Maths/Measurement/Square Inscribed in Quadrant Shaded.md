# Square Inscribed in Quadrant Shaded

## Statement

A square OABC is inscribed in a quadrant OPBQ. If OA = 20 cm, find the area of the shaded region (Use π = 3.14).

## Description

Source: KTBS Class 10 Maths Part I, Exercise 5.3, Question 13.

## Correct Answer

Shaded = quadrant − square (radius = OA√2 = 20√2): (1/4)π(20√2)² − 20².
