# Round Table Cover Six Designs Cost

## Statement

A round table cover has six equal designs. If the radius of the cover is 28 cm, find the cost of making the designs at the rate of ₹0.35 per cm² (Use √3 = 1.7).

## Description

Source: KTBS Class 10 Maths Part I, Exercise 5.2, Question 13.

## Correct Answer

Six 60° segments: cost ≈ ₹162.4 (standard textbook key).
