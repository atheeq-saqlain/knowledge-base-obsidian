# Quadrant Area Circumference 22

## Statement

Find the area of a quadrant of a circle whose circumference is 22 cm.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 5.2, Question 2.

## Correct Answer

C = 22 ⇒ r = 7/2; quadrant = (1/4)πr² = 77/8 cm².
