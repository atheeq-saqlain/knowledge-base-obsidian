# Prove 3 Plus 2 Root 5 Irrational

## Statement

Prove that 3 + 2√5 is irrational.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 8.3, Question 2.

## Correct Answer

Assume 3 + 2√5 = a/b in lowest terms. Then √5 = (a − 3b)/(2b), which is rational, contradicting that √5 is irrational. Hence 3 + 2√5 is irrational.
