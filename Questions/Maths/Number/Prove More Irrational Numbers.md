# Prove More Irrational Numbers

## Statement

Prove that the following are irrationals:
(i) 1/√2
(ii) 7√5
(iii) 6 + √2

## Description

Source: KTBS Class 10 Maths Part I, Exercise 8.3, Question 3.

## Correct Answer

(i) Assume 1/√2 = a/b ⇒ √2 = b/a rational — contradiction.
(ii) Assume 7√5 = a/b ⇒ √5 = a/(7b) rational — contradiction.
(iii) Assume 6 + √2 = a/b ⇒ √2 = (a − 6b)/b rational — contradiction.
