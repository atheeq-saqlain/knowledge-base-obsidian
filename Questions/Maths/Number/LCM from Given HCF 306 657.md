# LCM from Given HCF 306 657

## Statement

Given that HCF(306, 657) = 9, find LCM(306, 657).

## Description

Source: KTBS Class 10 Maths Part I, Exercise 8.2, Question 4.

## Correct Answer

22338

LCM = 306 × 657 / 9 = 22338.
