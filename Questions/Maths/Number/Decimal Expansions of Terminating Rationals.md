# Decimal Expansions of Terminating Rationals

## Statement

Write down the decimal expansions of those rational numbers in Exercise 8.4 Question 1 which have terminating decimal expansions.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 8.4, Question 2.

## Correct Answer

(i) 13/3125 = 0.00416
(ii) 17/8 = 2.125
(iv) 15/1600 = 0.009375
(vi) 23/(2³5²) = 23/200 = 0.115
(viii) 6/15 = 0.4
(ix) 35/50 = 0.7
