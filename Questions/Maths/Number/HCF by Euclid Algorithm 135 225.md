# HCF by Euclid Algorithm 135 225

## Statement

Use Euclid's division algorithm to find the HCF of:
(i) 135 and 225
(ii) 196 and 38220
(iii) 867 and 255

## Description

Source: KTBS Class 10 Maths Part I, Exercise 8.1, Question 1.

## Correct Answer

(i) 45
(ii) 196 (38220 = 196 × 195 + 0)
(iii) 51
