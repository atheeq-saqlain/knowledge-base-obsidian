# Prove Root 5 Irrational

## Statement

Prove that √5 is irrational.

## Description

Source: KTBS Class 10 Maths Part I, Exercise 8.3, Question 1.

## Correct Answer

Assume √5 = a/b in lowest terms. Then 5b² = a², so 5 | a² and 5 | a. Write a = 5c, giving 5b² = 25c², so b² = 5c² and 5 | b — contradicting coprimality. Hence √5 is irrational.
